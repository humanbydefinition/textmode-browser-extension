```text
움직이는 웹을 텍스트처럼 만들어 보세요.

[Textmode Overlay]는 브라우저용 실시간 ASCII 아트 생성기이자 동영상을 텍스트로 바꾸는 효과입니다. 호환되는 동영상이나 canvas를 선택하면, 살아 움직이며 완벽하게 정렬된 문자 그리드로 변하는 모습을 볼 수 있습니다. 밝기 음영과 윤곽선을 함께 사용하고, 색상과 글꼴을 고르고, 시각 효과를 쌓고, 구성이 마음에 들면 프레임을 내보내세요.

원본 미디어는 아래에 그대로 남아 있으므로, 언제든 효과를 블렌딩, 일시정지, 초기화, 교체 또는 제거할 수 있습니다.

textmode.js로 만들었습니다.


─── 사용해 보기

페이지가 호환되는 canvas 또는 HTML5 동영상을 제공하는 곳이라면 어디든 [Textmode Overlay]를 사용하세요:

  ▸ YouTube 재생을 실시간 ASCII 영상 아트로
  ▸ Twitch 스트림과 VOD를 textmode로 재해석
  ▸ Vimeo 및 기타 웹 동영상 플레이어를 스타일화
  ▸ 브라우저 게임, 데모, WebGL canvas 변환
  ▸ 음악 및 오디오 비주얼라이저에 텍스트 아트 느낌 더하기
  ▸ p5.js, Three.js, 제너러티브 아트, 크리에이티브 코딩 스케치 탐험
  ▸ 자신의 웹사이트에서 canvas 또는 동영상 요소 테스트

일부 보호된, 교차 출처 또는 샌드박스 처리된 미디어는 사용할 수 없을 수 있습니다. [Textmode Overlay]는 접근할 수 없는 프레임을 표시하고 페이지를 방해하지 않으면서 샘플링 오류를 보고합니다.


─── 오버레이 만들기

canvas 또는 동영상이 보이는 페이지를 여세요.

도구 모음:
  1  도구 모음에서 [Textmode Overlay] 아이콘 클릭
  2  "select media" 선택
  3  사용 가능한 대상 미리 보기
  4  대상 클릭

컨텍스트 메뉴:
  1  페이지 아무 곳이나 또는 동영상을 직접 마우스 오른쪽 버튼으로 클릭
  2  "Open Textmode Overlay" 선택
  3  오버레이 패널에서 "select media" 선택
  4  강조 표시된 canvas 또는 동영상 클릭

미디어 선택을 취소하려면 언제든지 Esc를 누르세요.


─── 빛, 윤곽 또는 둘 다로 그리기

밝기 패스와 윤곽 패스를 독립적으로 켤 수 있어 결과를 세 가지 방식으로 만들 수 있습니다:

  ▸ 밝기만
    ▹ 사용자 지정 글리프 램프로 밝기 값을 변환

  ▸ 윤곽만
    ▹ 감지된 가장자리를 문자로 된 그래픽 선으로 그리기

  ▸ 결합
    ▹ 밝기 기반 ASCII 음영 위에 윤곽을 겹치기

윤곽 임계값과 색상 감도를 미세 조정하고, 어느 패스든 반전하고, 해당 문자와 셀에 샘플링된 색 또는 고정 색을 선택하세요.


─── 스타일을 내 것으로

  ▸ 불투명도 컨트롤로 결과 블렌딩
  ▸ 문자 크기를 촘촘한 디테일부터 굵은 픽셀까지 설정
  ▸ 음영에 사용할 글리프 램프 선택 및 편집
  ▸ 번들로 제공되는 textmode 글꼴 순환
  ▸ 지원되는 TTF 또는 OTF 글꼴을 컴퓨터에서 업로드
  ▸ 원본 색을 샘플링하거나 알파 투명도를 가진 고정 문자, 셀, 배경 색 선택
  ▸ 보고 싶은 페이지 부분에서 패널을 끌어 옮기기
  ▸ 미디어를 다시 선택하지 않고 실험을 초기화하고 다시 시작


─── 라이브 효과 스택 만들기

CRT, 스캔라인, 블룸, 필름 그레인, 픽셀화, 색수차, 포스터라이즈, 임계값, 비네트, 그레이스케일, 세피아, 색조·대비·채도 컨트롤을 포함한 16가지 후처리 필터 중에서 선택하세요.

각 효과는 원본이 계속 재생되는 동안 켜고, 순서를 바꾸고, 펼치고, 조정할 수 있습니다. 스택 순서를 바꾸면 완전히 다른 결과가 나올 수 있습니다.


─── 프레임 저장

  ▸ TXT
    ▹ 작품을 일반 문자 그리드로 복사

  ▸ SVG
    ▹ textmode 결과를 어떤 배율에서도 선명하게 유지

  ▸ PNG
    ▹ 무손실 이미지로 내보내기

  ▸ JPG
    ▹ 가벼운 래스터 이미지로 내보내기


─── 워크플로 기억

가장 최근의 오버레이 프리셋은 도메인별로 따로 기억됩니다. 패널 위치도 기억되며, 사용자 지정 글꼴은 삭제할 때까지 브라우저가 관리하는 확장 프로그램 저장소에 로컬로 유지됩니다.


─── 기본적으로 비공개

계정, 클라우드 렌더러, 추적, 광고, 원격 미디어 처리가 없습니다. 확장 프로그램은 요청할 때만 오버레이를 만들고 변환, 설정, 글꼴, 내보내기를 브라우저 안에 유지합니다.

사용하는 권한:
  ▸ activeTab
    ▹ 확장 프로그램을 호출한 뒤에만 페이지에 접근

  ▸ scripting
    ▹ 페이지 내 오버레이 도구 시작

  ▸ storage
    ▹ 로컬 설정과 사용자 지정 글꼴 메타데이터 유지

  ▸ unlimitedStorage
    ▹ 지원되는 사용자 지정 글꼴 파일을 로컬에 유지

  ▸ contextMenus
    ▹ "Open Textmode Overlay" 마우스 오른쪽 버튼 동작 추가


─── 호환성

동일 출처, 중첩, srcdoc, 동적으로 추가된 iframe을 지원합니다. 교차 출처 또는 불투명 샌드박스 iframe 내부의 미디어는 대상으로 지정할 수 없습니다. 오염된 canvas(tainted canvas), DRM 동영상 및 기타 보호된 소스도 일반적인 브라우저 보안 규칙에 따라 픽셀 샘플링을 차단할 수 있습니다.
```
